### iCloud 配置错误诊断修复

用户首次配置失败后，服务器不带凭据的 CalDAV PROPFIND 测试收到 HTTP 401，证实当时可连接 Apple 入口，不能据此判断用户凭据是否正确。原统一错误隐藏了具体原因，现保留安全的失败阶段、HTTP 状态和网络错误码。新增认证、DNS、超时、TLS、地址限制及发现失败的脱敏测试，全部 40 项测试通过。真实账户失败原因仍需用户用更新后的向导重试确认。

### 中国区日历地址兼容修复

用户重试后失败在“列出日历 / DAV_UNTRUSTED_URL”。检查发现地址校验未包含 `.icloud.com.cn`，现补充中国区 CalDAV 入口与分区主机；日历相对地址改为相对于实际 calendar-home-set 解析，避免全球入口返回中国区目录后仍请求全球主机。服务器对中国区入口与一个分区节点的无凭据请求均通过 TLS 验证并收到 HTTP 401。新增跨区完整发现、重定向认证及伪造域名拒绝测试，全部 42 项通过。此前错误未保留被拒绝的具体地址，因此中国区遗漏是本次故障的推测原因，实际账户仍需重试确认。
